# Marko – GitHub Pages Edition

## So lädst du es hoch
1. Öffne dein Repository: https://github.com/lcsn1535-beep/Markos
2. Lade die Dateien `index.html`, `styles.css` und `app.js` aus diesem Ordner direkt ins Hauptverzeichnis (Root) des Repositories hoch. Nicht den gesamten Ordner `public` hochladen.
3. Wenn GitHub fragt, bestätige mit **Commit changes**.
4. Öffne **Settings → Pages**. Unter **Build and deployment** wähle **Deploy from a branch**, Branch `main` (oder `master`) und Ordner `/ (root)`, dann **Save**.
5. Warte kurz und öffne `https://lcsn1535-beep.github.io/Markos/`.

## Wichtige Grenzen dieser GitHub-only-Version
Diese Version ist eine statische Demo, damit die Oberfläche ohne Server auf GitHub Pages funktioniert. Benutzer, Passwörter und Chatverlauf liegen im Browser (`localStorage`) und sind **nicht sicher**: Jeder kann den Code ansehen; Daten werden nicht zwischen Geräten synchronisiert. Das Admin-Panel ändert nur lokale Demo-Daten. Die Antworten sind simuliert und keine echte KI. Bildschirmfreigabe funktioniert nur nach Browser-Erlaubnis; der Bildschirm wird hier nicht von einer KI analysiert.

Für echte KI-Antworten, sichere Konten, zentrale Benutzerverwaltung und echte Screenshot-Analyse ist technisch ein Backend oder ein externer KI-Dienst nötig. Es ist nicht möglich, diese Funktionen sicher und wirklich vollständig nur mit GitHub Pages bereitzustellen.
